# ⚡ Сповіщення про графік відключень — Луцьк / Волинь

Кожні 10 хвилин бот перевіряє офіційні графіки погодинних відключень (ГПВ) «Волиньобленерго».
Коли з'являється графік на новий день або змінюються години для вашої черги, він надсилає
вам у Telegram картинку графіка та години без світла.

Працює безкоштовно на GitHub Actions, ваш комп'ютер для цього не потрібен.

---

## Крок 1. Дізнайтеся свою підчергу

На сайті «Волиньобленерго» введіть свою адресу:
https://energy.volyn.ua/spozhyvacham/perervy-u-elektropostachanni/cherga/

Запишіть підчергу у форматі **3.2** (номер черги, крапка, номер підчерги).

## Крок 2. Створіть свого Telegram-бота

1. У Telegram знайдіть **@BotFather** (перевірте, що поруч із ним синя галочка).
2. Напишіть йому `/newbot`, придумайте назву та ім'я, яке закінчується на `bot`.
3. BotFather надішле **токен** вигляду `123456789:AAE...`. Збережіть його і нікому не показуйте.
4. Відкрийте свого нового бота і натисніть **Start** (або напишіть йому будь-що).

## Крок 3. Дізнайтеся свій chat id

Відкрийте в браузері адресу, підставивши свій токен:

```
https://api.telegram.org/bot<ВАШ_ТОКЕН>/getUpdates
```

Знайдіть на сторінці `"chat":{"id":123456789` — це число і є вашим **chat id**.
Якщо там порожньо (`"result":[]`), напишіть своєму боту ще одне повідомлення й оновіть сторінку.

## Крок 4. Створіть репозиторій на GitHub

1. Зареєструйтеся на https://github.com (безкоштовно).
2. Натисніть **+** → **New repository**, назва, наприклад, `svitlo-bot`.
3. Оберіть **Public**. Для публічних репозиторіїв GitHub Actions безкоштовний без обмежень,
   а для приватних хвилин на запуски перевірок кожні 10 хвилин не вистачить.
   Токен і chat id ми збережемо як секрети, і інші люди їх не побачать.
4. Натисніть **Create repository**.

## Крок 5. Завантажте файли

1. У репозиторії натисніть **uploading an existing file** (або **Add file → Upload files**).
2. Розпакуйте архів і перетягніть у вікно **весь його вміст разом із папкою `.github`**.
   - Папка `.github` прихована. На Mac її показує комбінація `Cmd + Shift + .`,
     у Windows: Провідник → Вигляд → «Приховані елементи».
   - Якщо папка не завантажилася, створіть файл вручну: **Add file → Create new file**,
     в імені файлу наберіть `.github/workflows/check.yml`, вставте вміст файлу `check.yml`
     і натисніть **Commit changes**.
3. Натисніть **Commit changes**.

Мають з'явитися файли: `bot.py`, `requirements.txt`, `README.md`, `.github/workflows/check.yml`.

## Крок 6. Додайте налаштування

У репозиторії відкрийте **Settings → Secrets and variables → Actions**.

На вкладці **Secrets** натисніть **New repository secret** і додайте два секрети:

| Name | Значення |
|---|---|
| `TELEGRAM_BOT_TOKEN` | токен від BotFather |
| `TELEGRAM_CHAT_ID` | ваш chat id |

На вкладці **Variables** натисніть **New repository variable** і додайте:

| Name | Значення |
|---|---|
| `QUEUE` | ваша підчерга, наприклад `3.2`. Кілька підчерг пишіть через кому: `3.2,5.1` |
| `NOTIFY_ALL` | *(необов'язково)* `true`, якщо хочете отримувати кожну нову редакцію графіка, навіть коли для вашої черги нічого не змінилось |

## Крок 7. Перевірте, що все працює

1. Відкрийте вкладку **Actions**. Якщо GitHub попросить, натисніть кнопку, яка вмикає workflows.
2. Зліва оберіть **«Перевірка графіка відключень»**, а потім **Run workflow → Run workflow**.
3. Через хвилину-дві вам у Telegram має прийти графік на сьогодні (і на завтра, якщо його вже опублікували).
   Якщо графіків на ці дні ще немає, повідомлення не буде. Це нормально.

Після цього бот сам перевірятиме графік кожні 10 хвилин.

---

## Якщо щось не працює

- **Червоний хрестик у вкладці Actions.** Відкрийте запуск і крок «Перевірити графік»: там буде текст помилки.
- **«Не задано TELEGRAM_BOT_TOKEN…»** означає, що секрет назвали з помилкою. Назва має бути точно як у таблиці.
- **Помилка Telegram 400 / chat not found.** Перевірте chat id і переконайтеся, що ви натиснули Start у своєму боті.
- **«Не вдалося автоматично прочитати години».** «Волиньобленерго» змінило вигляд картинки.
  Графік усе одно прийде, просто без тексту з годинами.
- **Перевірки зупинилися.** GitHub вимикає запуски за розкладом у репозиторіях без змін понад 60 днів.
  Бот сам зберігає `state.json`, тож коли графіки оновлюються, такого не станеться. Якщо ж
  запуски вимкнулися, увімкніть їх у вкладці Actions.

## Важливо

- Дані беруться з того ж архіву графіків, який показує сайт «Волиньобленерго». Обов'язковим
  є лише графік на офіційному сайті, а через перемикання черг світло може вимикатися на 20–30 хвилин раніше чи пізніше.
- Аварійні та екстрені відключення (ГАВ) часто відбуваються без графіка, і бот про них не знає.
